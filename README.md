# proyecto_ingenieria_de_software
Sistema de Gestión Agricola(SIGAGRO): plataforma que permite administrar cultivos, inventario de insumos y producción agrícola, facilitando la toma de decisiones del productor.
Objetivo general
Desarrollar un sistema de información web denominado SIGAGRO que permita gestionar de manera eficiente la información relacionada con cultivos, inventario de insumos y producción agropecuaria, facilitando la toma de decisiones de los productores.
Integrantes del equipo
Marcos Saraguro Merchan, Jaime Guallpa Guaman.
Funcionalidades principales
•	Registro y control de cultivos.
•	Gestión de inventario de insumos agropecuarios.
•	Generación de reportes de producción.
•	Registro de actividades agrícolas (siembra, riego, cosecha
