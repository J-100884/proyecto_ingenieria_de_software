# SIGAGRO - Sistema de Gestión Agropecuaria 🌾

## 🎯 Objetivo General
Desarrollar un sistema de información web denominado **SIGAGRO** que permita gestionar de manera eficiente la información relacionada con cultivos, inventario de insumos y producción agropecuaria, facilitando la toma de decisiones de los productores[cite: 1].

---

## 🛠️ Metodología de Desarrollo
El equipo ha seleccionado un **modelo de proceso incremental basado en principios de Scrum**, lo que permite dividir el desarrollo del sistema en entregas parciales y funcionales adaptadas al calendario académico[cite: 1].
